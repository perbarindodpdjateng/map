Hubungkan Google Sheets

Deploy Google Apps Script sebagai Web App, lalu tempel URL-nya di bawah. Data akan disimpan & dibaca langsung dari Spreadsheet Anda.

  1. Buka Google Sheets → Extensions → Apps Script
  2. Paste kode dari file AppsScript_BPR_Sheets.gs
  3. Deploy → New deployment → Web App
  4. Execute as: Me  |  Who has access: Anyone
  5. Salin URL deployment → tempel di bawah
